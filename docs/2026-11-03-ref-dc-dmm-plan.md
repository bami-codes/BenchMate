# REF 지속 DC / 독립 멀티미터 QA

사용자의 “해보자 그러면”과 USB 재연결·DC 2 V / 1 mV 표시 준비 완료 응답에 따른 계측 QA다.
진단 실행이나 예약 검증이 아니며, 유료 호출 0회·비용 $0, 펌웨어 업로드 없음이다.

- 배선: design-01 고장 DUT 유지, B28–B35 1 kΩ, A23–A45의 A3 REF,
  D50–G50 및 I50–A4의 A4 REF, B50–B23 유지. E30–A55 부하는 없음.
- 출력 순서: C → L → C → H → C → C → H → C → L → C.
  기존 명목 환산 C=1.646 V/1376, L=1.146 V/958, H=2.146 V/1793.
  이는 구동 쪽 값이며 D50 REF의 기대 측정값이 아니다.
- 새 비무장 부팅 확인 뒤 ARM 한 번. 이후 같은 USB 신원·부팅·출력 코드를 확인한다.
  실패 시 재시도·재무장·자동 복구하지 않는다.
- 각 수준의 지속 DC 확인 뒤 5초 기다린다. 검정 프로브는 기존 파란 GND,
  빨강은 D50의 점퍼 금속 부분. DC 2 V 범위에서 2초 간격 표시값 세 개를 그대로 기록한다.
- DMM 판독 후 같은 수준으로 512프레임 / 2 ms HOLD를 취득한다. 취득 뒤 REF로 복귀하고
  다음 수준을 설정한다. DMM과 ADC는 같은 수준의 순차 측정이며 동시 측정이 아니다.
- 전기적 범위·통신·부팅 검사 실패 시 다음 수준을 보내지 않는다. 기존 3 mV REF 기준은
  유지한다. 초과는 실패 플래그로 남기되 이 QA는 전기적 범위 안에서 계획한 DC 수준을 수집한다.
  어떤 결과도 진단 통과나 이전 파일럿의 합격으로 재분류하지 않는다.
- 정상 종료는 C/REF 복귀를 확인한다. 중단·통신 실패 시 출력 상태를 확인했다고 주장하지 않는다.

새 기록기는 기존 실행 소스 76개를 변경하지 않고 그 해시 및 자신의 해시를 계획에 고정한다.
단위 검사 8개가 통과했다. 원시 응답·명령·부팅·DMM 원문·각 단계의 소스 사본을 보존한다.

해석은 [기존 로그 분석의 분기](2026-11-03-ref-investigation.md)를 따른다. D50의 반복 DC 이동은
실제 전압 이동의 근거다. D50이 평평하다는 것만으로 ADC 다중화 원인을 확정하지 않는다.
ADC가 같은 DC 수준에서 계속 움직이는지, G50 및 접지 경로도 안정적인지 확인해야 한다.
