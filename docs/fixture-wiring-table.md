# U2 측정 버퍼와 A1–A4 전체 결선표

**현재 작업(2026-10-29):** 100.8kΩ 입력 풀다운 **B13–E16** 설치 후 전원/REF/B13/D45=4.88/1.631/0.003/0.002V가 보고됐다. C13은 기존 저항 몸통에 가려 미사용이다. 첫 PING은 무응답으로 끝났고, 작업자 단일 RESET 뒤 새 초기 부팅을 확인했다. REF 목표 1.631V(코드 1369) 설정 및 512프레임 취득이 통과했다. 현재 같은 출력을 유지하며 B13/D35/D40/D45/D50의 새 DC 2V 보고를 기다린다. 새 B13 접점은 추가한 저항 다리이며 이전의 자유 기둥이 아니다. 아래의 이전 상태 문단은 경과 기록이다. 긴 USB 감시 시험은 재개하지 않는다.

상태(2026-10-29, 한국 시간): 작업자가 50열 1kΩ→짧은 점퍼 교체·통전·A4 재연결을 완료하고 전원/D50/G50=4.86/1.63/1.63V를 보고했다. 수정 ADC 펌웨어를 수동 부트로더 모드에서 업로드했고, 실제 사용 채널의 취득 전후 설정값 255와 동일 부팅 ID를 확인했다. 2ms 간격 512프레임씩 세 블록이 원시 취득 검사를 통과했다. 드문 큰 편차가 반복돼 잡음·보정 완료로 선언하지 않는다. 현재 출력은 1.63V 목표이며, DC 2V 범위의 D35/D40/D45/D50 표시값을 기다린다.

USB를 뺀 상태에서 조립한다. 2026-10-29 추가 통전 보고 뒤, 첫 전원 확인은 사진 대신 작업자의 칩 방향·노출 다리 확인과 보고된 무전원 검사를 바탕으로 진행하기로 했다. 아래 배선표와 기존 U1, Arduino 5V/GND/A0 배선, 기존 1kΩ 풀다운 두 개는 유지한다. 과거 임시 A9–A13 점퍼는 제거된 상태를 유지한다. 추가 DUT는 연결하지 않는다.

A가 왼쪽 위인 기존 사진 방향, 위쪽에 인쇄된 열 번호를 위·아래 모두에 사용한다. `아두이노`라고 쓴 항목만 보드 핀이고, 나머지는 브레드보드 구멍이다. 새 배선은 전원 레일에 직접 꽂지 않아 가운데 레일 단절을 건너지 않는다. 아래 표의 30·35·40·45·50번은 중앙 단자부 열이며 전원 레일이 아니다.

준비물(2026-10-29 A4 수정 반영): 두 번째 LM358N, 10kΩ 2개, ADC용 1kΩ 3개, 104J100(0.1µF) 1개, 점퍼 19개. 처음 설치했던 50열 1kΩ 한 개만 짧은 점퍼로 교체한다. 저항값은 회로 밖에서 확인한다. 저항과 이 필름 커패시터는 방향 구분이 없다.

지금은 11·14·15번 점퍼를 모두 설치한다. 보정 상태에서 A1은 직결 IN, A2는 같은 IN 신호를 U2로 버퍼링한 값, A3는 션트 전 구동 출력, A4는 REF다. 실제 전압이나 오프셋이 정확히 같다는 뜻은 아니다. 보조 버퍼는 입력을 REF에 고정하고 출력에 10kΩ 풀다운을 둔 상태이며, 아두이노 A5는 연결하지 않는다. 현재 계측 펌웨어는 A1–A4만 취득한다.

2026-10-29 수정 근거: A4 외부 선을 분리한 무전원 보드에서 A4–5V가 프로브 양방향 모두 5.19~5.20kΩ로 보고됐다. 기존 0.994kΩ 직렬 저항과 계산하면 REF 1.62V에서 A4 약 2.14V로, 보고된 2.15V를 설명한다. 24번 교체는 **내부 버퍼 REF 전용**이며, 외부 신호 입력이나 다른 ADC 보호 저항에 적용하지 않는다. REF의 기존 1.001kΩ 풀다운도 유지한다. 점퍼 교체 후 D50/G50의 동일 표시와 A4의 약 1.64V 보정 전 환산값을 확인했다. ADC 잡음·부하 특성은 계속 검증한다. 부품 위치를 특정하거나 보드의 특정 SMD 저항을 제거하는 작업은 하지 않는다.

나중의 DUT 연결 구멍은 **IN=A35, OUT=B30, RET=C50**로 비워 둔다. DUT 연결 전 15번만 제거한다. 11번은 션트 실험 때 교체하고, 14번은 보조 프로브 사용 때 제거한다. RET는 REF이며 파랑 GND 레일과 연결하지 않는다. 이번 단계에서는 DUT를 연결하지 않는다.

조립 후에도 USB를 뺀 채 빨강↔파랑 레일에 지속적인 통전음이 없는지, C20↔기존 빨강 레일·I23↔기존 파랑 레일·H20↔H21·C21↔C22가 각각 직접 연결인지 확인한다. 커패시터·저항의 노출된 다리가 옆 노드에 닿지 않는지도 확인한다. 이 검사와 사진 확인은 실제 설치 상태 확인이며, 위의 연결 계산 검증을 대체하지도 계측 성능을 보증하지도 않는다.

근거: [기존 U1 조립 기록](fixture-assembly.md), [ST LM358 핀 배치 p.4](https://www.st.com/resource/en/datasheet/lm358.pdf). 연결 계산 검증에서는 기존 구멍 중복 없음, 전원/GND 분리, 두 팔로워 피드백, 기존 설계의 네 ADC 직렬 저항, 출력끼리 직결되지 않음, 보정 점퍼 제거 시 IN/OUT 분리, 션트 점퍼 제거 시 병렬 우회 경로 없음, DUT용 세 구멍 여유를 확인했다. 조립·통전은 작업자 완료 보고다. 칩 방향과 WiFi에서의 첫 전원·REF·중간 전압 보고는 받았다. Minima로 보드 연결을 옮긴 뒤 공급 전압과 J10 REF도 보고받았다. A4–5V 저항 확인은 보고받았다. 수정 설계 계산에서도 구멍 중복 없음, A1~A3 직렬 저항 유지, A4와 버퍼 REF 직결, 전원/GND 및 다른 출력과 직결되지 않음을 확인했다. 24번 교체·A4 재연결·통전·전압 확인은 보고받았다. DC 2V 표시값은 D35/D40/D45/D50=1.631/1.630/1.631/1.629V, U1 3번 핀=1.629V로 보고됐다. 이후 새 ADC 시도는 시작 PING 무응답으로 중단됐다(측정 명령 미전송). 별도 PING도 무응답이었으나 Minima 포트는 목록에 남아 있었다. 이후 D50과 보드 SDA는 모두 1.633V로 보고됐다. 사용자는 USB 재연결도 확인했고, 새 부팅 ID에서 명시적으로 출력을 다시 설정한 뒤 512프레임 취득이 통과했다. 이전 A4의 양의 채널 차이는 이번 블록에서 재현되지 않았으나 원인은 확정하지 않았다. 새 전원/D45/D50은 4.89/1.636/1.633V로 보고됐다. 이후 시험을 통과한 DC 유지 펌웨어를 확인된 두 번 RESET 뒤 업로드했고, 새 부팅 ID에서 REF 코드 1368 설정 후 낮은 지점 코드 531을 유지 중이다. 낮은 지점은 D35/D40/D45/D50=0.629/0.628/0.629/1.633V 보고 뒤 512프레임 취득이 통과했다. 현재는 같은 부팅에서 중간 지점 코드 1368을 유지하고, 같은 네 곳을 DC 2V로 읽도록 요청한 상태다. 배선은 바꾸지 않았으며 A4는 계속 고정 REF다. 다점 보정과 통신 원인 확인은 아직 완료되지 않았다. 개별 저항값이 필요한 보정에서는 회로 내 병렬 경로를 배제해 측정하고 원래 위치로 복원한다.

최신 이상 보고(2026-10-29): 중간점 D35/D40/D45가 3.28V였고, 사용자는 빨강·파랑 레일 프로브용 기둥이 닿았다고 보고했다. 현재 표의 픽스처 배선을 바꾸는 단계가 아니다. **USB를 분리하고 전원 LED가 꺼진 뒤, 추가했던 프로브 기둥 두 개만 제거하고 레일 간 무전원 통전을 확인하도록 요청했다.** 공급선과 회로 배선은 유지하며 재연결하지 않는다. 완료 보고는 아직 없고, 이후 프로브 배치는 노출된 5V/GND 금속 끝이 접촉하지 않게 정해야 한다.

이후 확인: 사용자가 USB 분리·프로브 기둥 두 개 제거·지속 통전음 없음을 보고했다. 다음 측정 접점은 **GND용 기둥 하나만 J27**에 설치하고 무전원 상태에서 파랑 레일과 통전 확인하도록 요청했다. 전원은 기존 첫 분압저항의 **A3 쪽 다리**에 프로브를 대서 읽고, REF는 기존 J10을 쓴다. A3에는 부품을 추가로 꽂지 않고, 5V용 자유 기둥도 다시 만들지 않는다. J27은 설계상 비어 있는 GND 노드임을 확인했지만 실제 설치·통전·재연결 후 전압 보고는 아직 없다.

실제 배치 정정: 사용자는 **기존 파랑 레일 GND 기둥 유지, 빨강 5V 기둥만 제거**했다고 명확히 했다. J27 이동은 수행하지 않았고 현재도 기존 파랑 레일이 멀티미터 기준이다. 전원/REF=4.88/1.63V 보고 후 최초 PING은 실패했으며, 사용자 단일 RESET 뒤 새 부팅과 명시적 REF 출력 코드 1368을 확인했다. 다음은 DC 20V로 B13/A11/D50의 실제 전압을 확인하는 단계다.

최신 전압 확인: B13/A11/D50=1.62/3.4/1.64V로 보고됐다. 구동 출력이 입력을 따르지 않아 보정은 계속 중단한다. USB 분리·전원 LED 꺼짐을 확인한 뒤 U1 입력·피드백 접촉을 점검할 예정이며, 아직 칩 고장으로 확정하지 않는다. 다른 배선과 칩은 옮기지 않도록 요청했다.

접점 정정: B13·A11 프로브 기둥은 전날 밤 제거했고, 위의 1.62V·3.4V는 실제 U1 5번·7번 다리에서 직접 잰 값이라고 사용자가 명확히 했다. USB 분리·LED 꺼짐과 B12↔D11 통전은 확인됐다. 실제 6번 다리의 접촉까지 확인하기 위해 U1 금속 다리 6번(E12)↔7번(E11) 통전을 요청했으며, USB는 계속 분리한다. 칩이 걸렸다는 원인 판정은 아직 하지 않는다.

직접 피드백 확인 완료: 사용자가 실제 6번↔7번 금속 다리 통전음을 보고했다. 배선과 칩을 그대로 둔 전원 재인가 시험으로 진행한다. DC 20V로 전환 후 같은 USB 케이블·포트에 연결하고, 전원은 기존 분압저항 A3 쪽 다리, REF는 D50에서 재도록 요청했다. 재연결·새 전압 보고는 대기 중이며 아직 DAC를 설정하지 않았다.

재인가 후 확인: USB 연결 및 전원/REF=4.86/1.62V가 보고됐다. 새 초기 부팅을 확인한 뒤 DAC 목표 1.62V(코드 1365)를 명시적으로 설정했고 후속 응답도 일치했다. 다음은 실제 U1 5번(E13)·6번(E12)·7번(E11)과 D50 전압 확인이며, 그동안 출력·펌웨어를 변경하지 않는다. 구동 버퍼 회복은 아직 미확인이다.

중간점 회복 보고: 실제 U1 5/6/7번과 D50 모두 1.62V로 보고됐다. 이후 낮은 지점 설정 전 PING이 무응답이어서 0.62V 명령은 보내지 않았다. USB 전송 오류를 별도로 보존했다. 사용자가 RESET 한 번을 확인한 뒤, 배선·펌웨어를 바꾸지 않고 코드 1365에서 한 연결을 유지하는 10분 PING 시험을 16:45:59 KST에 시작했다. 결과는 대기 중이다.

10분 결과: 600.011초 동안 300회 응답이 같은 부팅·코드를 유지했다. 해당 구간 Minima 커널 로그 조회는 오류 포함 메시지 0건이었다. 작업자의 무접촉 최종 확인은 대기 중이다. 같은 부팅에서 동일한 1.62V DC 유지·안정화도 통과했다. 현재 PING 전용 감시를 유지하며 실제 U1 5번 / D35 / D40 / D45 / D50을 DC 2V로 읽도록 요청했다. 배선은 바꾸지 않았고, ADC 취득 전에는 감시 연결을 명시적으로 닫아야 한다.

정밀 중간점 완료: 사용자가 10분 무접촉을 확인했고, U1 5번 / D35 / D40 / D45 / D50=1.620/1.620/1.619/1.620/1.628V를 보고했다. 감시 650회·1305.597초를 정상 종료한 뒤 같은 부팅에서 512프레임 취득이 통과했다. 현재는 경계 안쪽의 0.65V 목표(코드 548)를 유지하며 같은 다섯 곳의 DC 2V 값을 기다린다. 새 PING 감시 연결이 열려 있으므로 다음 취득 전에 STOP으로 종료해야 한다. 배선·펌웨어는 바꾸지 않았다.
