# DMM 입력 표현 보완 — 첫 ADC 취득 전

사용자는 첫 C 수준에서 “초반엔 좀 요동치다가 지금은 1.630 유지”, 이어서 “1.630~1.631”이라고
보고했다. 이를 3개의 개별 판독값으로 만들지 않는다. 첫 계획의 3회 판독 원칙에서 벗어난
**범위 관찰**임을 표시하고, 개별 시각·개수·2초 간격은 확인되지 않았다고 기록한다.

이 보완은 첫 DMM 보고를 받은 뒤, 첫 짝지을 ADC 취득 전에 고정했다. 사전 등록된 입력 규칙이라고
주장하지 않는다. 이후에도 실제 3개 값 또는 사용자가 관찰한 범위를 원문과 함께 보존한다.
범위의 중간값을 실제 판독값으로 만들지 않으며, 정밀도나 안정성을 과장하지 않는다.

원본 기록기와 기존 실행 소스는 유지한다. 별도 입력 확장기가 원본의 부팅·DC·HOLD·전기적 범위
검사를 재사용한다. 출력 수준·순서·부팅·배선·펌웨어·3 mV 기준·진단 집계 제외는 모두 동일하다.
추가 유료 호출은 0회다. 원본 계획과 확장 전 상태, 확장 소스 해시를 따로 보존한다.
