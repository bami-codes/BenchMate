# 11월 1일 실물 작업 순서 — 16시 예정

이 문서는 앞으로 할 작업의 순서다. 사진은 과거 상태이고, 예정 시각 도달은
USB·배선 확인이나 실행 승인을 대신하지 않는다. 오늘 오전 사진 시험은
비전 1회·SAM 2회로 끝났고 하드웨어 명령은 보내지 않았다.

1. **B5 시작 상태 확인.** [B5 안내서](b5-operator.md)의 USB 분리·저항만 남긴
   대조 상태·OUT/REF 무전원 통전·재연결을 실제로 확인한다. 마지막 보고를
   현재 상태로 재사용하지 않는다. 멀티미터 전압 중심 맞춤은 반복하지 않는다.
2. **저항 대조 → 다이오드 요청 → 학습 → 구조 제안 → 예약 검증.** Spark와
   벤치는 고정한 도구와 가드만 사용한다. 다이오드는 요청 시 무전원 상태에서
   미니 D8(OUT)에 띠 없는 쪽, D13(REF)에 띠 있는 쪽으로 설치한다.
   학습과 예약 검증 사이에는 USB·RESET·배선을 바꾸지 않는다. 실패는 그대로
   보존하며 자동 재시도하지 않는다. 모델/예측 공개 후 예약 데이터를 취득한다.
3. **B5 종료 기록과 출력 상태 확인 후 D01 준비.** USB를 분리하고 B5 다이오드를
   제거한 뒤, 별도 확인 절차로 원래 C와 추가 C를 준비한다. 설치를 요청하거나
   완료했다고 이 문서만으로 기록하지 않는다. 실제로 두 C가 꽂힌 상태에서
   위에서 사진 한 장을 찍는다. B5 도중 D01 사진을 위해 회로를 바꾸지 않는다.
4. **Spark가 지휘하는 D01 수리.** [수리 계획](spark-d01-repair-plan.md)에 따라
   진단 → Spark의 수리 요청 → 수리 후 예측 고정·푸시 → 작업자 수리 → 새 부팅
   측정과 예약 검증을 별도 실행으로 남긴다. **수리 실행기 구현·검증은 아직
   남아 있다.** 기존 진단 실행기나 이전 스크립트 수리 기록으로 대신하지 않는다.

B5의 현재 준비 파일은
`examples/b5-unloaded-protocol/2026-10-31-after-design-replay/protocol.json`이다.
오늘 사진 시험은 계측 소스를 바꾸지 않아 이 파일의 소스 해시가 여전히 맞는다.
실물용 Meta 요청 범위와 횟수는 실제 시작 전에 별도로 확인한다. 사진 시험의
3회 요청을 실물 실험 요청으로 확대하지 않는다.

SAM은 이번 `capacitor` 요청에서 0개를 반환했다. 따라서 수리 영상의 필수
동작으로 잡지 않는다. 저항 분할은 한 사진에서의 표시용 결과이며 추가
커패시터 식별, 전기적 연결 또는 수리 정확성을 증명하지 않는다.
