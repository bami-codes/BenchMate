# 수동 DMM 비교 중단과 REF 접촉 경로 QA

Nov 3 D50 지속 DC QA는 손으로 유지하는 프로브의 mV 판독을 반복하는 방법이 실용적이지 않다는
사용자 피드백에 따라 중단했다. 계획 10단계 중 DMM/ADC 짝 5개와 6번째 DMM 값까지 보존했다.
마지막 보고는 C=1.632 V다. 추가 DC/CAPTURE 없이 PING만으로 같은 부팅의 C/1376을 확인했다.
원인 확정이나 교정 완료가 아니다. 새 Spark 0회·비용 $0, 펌웨어 변경 없음이다.

## 관측의 한계

DMM 보고 범위는 1.629–1.638 V다. 개별 3회 판독이나 접촉 안정성은 확인되지 않았고 ADC와
동시 측정도 아니다. 취득한 5블록의 명목 ADC 평균 범위는 A3=41.590 mV, A4=103.843 mV다.
첫 C와 다음 C의 A4 평균도 약 65.855 mV 달랐다. 고정된 입력 혼입 비율을 가정하지 않는다.
기존 3 mV 기준은 초과로 보존하며 진단·예약 검증·집계에 사용하지 않는다.

기존 조립 기록에는 USB와 A4 외부선을 분리한 상태의 A4–5V=5.19–5.20 kΩ 보고가 있다.
이는 보드 내부의 pull-up 같은 경로를 실측한 것이며 특정 저항 부품을 확인한 것은 아니다.
과거 D50–G50 직렬 1 kΩ에서 약 0.53 V 차이가 생겼고 짧은 점퍼로 교체한 이력이 있다.
현재 사용자는 D50 점퍼의 마모를 지적했다. 접촉 저항이 생기면 A4 쪽 값을 올릴 수 있으므로
이 알려진 경로의 접촉을 먼저 정비한다. A3 변동이나 전체 원인이 설명됐다고 단정하지 않는다.

## 한 번의 정비와 자동 비교

USB를 빼고 LED가 꺼진 뒤, 회로 밖에서 통전 확인한 새 짧은 점퍼로 D50–G50만 교체한다.
A23–A45, I50–A4, B50–B23, 1 kΩ, DUT, 무부하 설정을 유지한다. 프로브를 치우고 같은 USB로
재연결한다. 실제 작업 완료 보고 전에는 새 출력을 시작하지 않는다.

별도 QA는 기존 PhysicalBench의 보호 검사를 그대로 사용하며 첫 실패에서 중단한다.
새 부팅에서 ARM 한 번, C HOLD×3, ±0.2 V STEP, C HOLD, ±0.5 V STEP, C HOLD 순서다.
STEP은 512프레임/500 µs, HOLD는 512/2 ms이며 기존 타이밍·DAC 코드 검사도 적용한다.
자동 취득은 통상 1분 안팎이며 손으로 mV를 반복 판독할 필요가 없다. 실패하면 재시도하지 않는다.
Spark 대신 순서를 정하는 진단이 아니라, 정비 후 고정된 계측기 점검이다.
기존 소스 76개·펌웨어·기준은 바꾸지 않는다. 로그를 모두 보존하고 평가에서 제외한다.
