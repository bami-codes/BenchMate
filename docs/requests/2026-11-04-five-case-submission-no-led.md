# Claude 요청: 최종 제출 5개 사례, LED 06 제외

사용자가 2026-11-04 KST에 LED 사례를 아예 하지 않고 제외하라고 결정했다.
현재 범위의 기준은 [최종 제출 범위](../2026-11-04-five-case-submission-scope.md)와
[범위 JSON](../2026-11-04-five-case-submission-scope.json)이다.

사이트·README·영상·제출문에서 다음을 반영해 달라.

- 제출 사례는 **01·04·02·05·03, 서로 다른 수동 축소 회로 5개**로 쓴다.
- LED 06 카드·탐색 링크·예정 표시·남은 작업과 “여섯 사례”, “5/6”, LED 예정 일정을 빼 준다.
- 완료한 다섯 사례와 각 복원 재실행을 중심으로 구성한다. 수동 축소 회로라는 범위를 유지한다.
- 기존 실패·기권·수정·후속 실행은 보존한다. 다섯 사례가 끝났다는 이유로 “5/5 정확도”나 첫 시도 전부 성공을 주장하지 않는다.
- 복원 문구는 **No mismatch in the tests Spark chose**로 유지한다.
- 과거 소프트웨어/모의/회로도 6개 기록은 역사 기록이다. 이를 실물 6개 완료로 소개하지 않는다.

사례03도 전체 파이프라인이 완료됐다. 최신 증거는
`examples/reading-cohort/2026-11-03/records/20261104T051005-fac3d07c86/case03-evidence-map.json`에
원래 고장 진단·Spark의 SAM 대응·2.22kΩ 분리 읽기·10kΩ 복원·consistent 재실행·복원 사진/SAM 경로가 있다.
기존 실패는 별도 보존되어 있다. 복원 SAM은 표시 전용이고 추가 Spark 지목/값 판독은 하지 않았다.

Codex는 이 요청에서 사이트·README·영상·제출문을 수정하지 않았다.
direction 문서에는 최신 범위 링크 안내만 추가하며, 나머지 Claude의 기존 미커밋 변경은 수정·커밋하지 않는다.
