# 다른 작업자의 D01 수리 세션

이 문서는 **아직 하지 않은 관찰 세션의 절차**다. D01 실물 수리가 먼저 통과한 뒤 사용한다.
한 사람의 완수는 그 사람·그 장치·그 조건의 사용 사례다. 일반인 성공률이나 독립 회로 두 개의
검증으로 확대하지 않는다. 지원받은 실행도 보존하고, 도움 없이 했다고 바꾸지 않는다.

## 시작 전에 고정할 것

- 세션 ID와 익명 작업자 코드, 회로·멀티미터 경험의 본인 설명.
- 이미 해 본 D01을 반복하는지, 개발에 쓰지 않은 추가 C 값만 숨기는지.
  숨기는 경우에도 정상 설계는 10 kΩ·1 µF이며, 수리는 추가 C 제거로 한정한다.
  R, 정상 C, 회로 구조까지 숨긴 새 문제를 이 실행기에 맡기지 않는다.
- 사용 프로토콜·실행기·정상 설계 검토 파일의 해시와 시작 배선 상태.
- 작업자에게 보여 준 안내, 미리 연습한 조작, 이전 결과를 본 여부.
- 촬영·공개에 대해 작업자가 실제로 동의한 범위. 이름·얼굴은 필요하지 않다.
  원본 영상과 개인 정보는 `video/raw/` 또는 비공개 로컬 기록에 둔다.

밀봉 변형의 값은 조립 담당자가 따로 보존한다. 공개 사전 고정에는 무작위 salt를 포함한
정답 JSON의 SHA-256만 올리고, 값과 salt는 측정 후 공개한다. 부품 후보가 적으면 값만의
해시는 쉽게 역추정할 수 있다. 모델에 정답 파일·부품 사진·조립 메모를 전달하지 않는다.
기존 D01 반복이면 밀봉·블라인드라고 부르지 않는다.

## 처음 읽어 줄 안내

> 이 회로의 정상 설계는 10 kΩ와 1 µF입니다. BenchMate가 측정을 고르고,
> 필요하면 화면에 배선 변경을 요청합니다. 요청된 작업만 따라 해 주세요.
> 배선을 바꾸기 전에는 USB를 빼고 전원 표시가 꺼질 때까지 기다립니다.
> 헷갈리면 언제든 질문하거나 멈출 수 있습니다. 질문과 도움은 그대로 기록합니다.

추가 커패시터가 결함이라는 답이나 다음에 어떤 실험이 나오는지는 미리 설명하지 않는다.
구멍을 읽는 법과 USB-off 절차를 알려줬다면 그 설명과 소요 시간은 기록한다.
이 세션은 사용성 관찰이며 참가자 시험이 아니다.

## 실행과 관찰

1. 화면 녹화와 손 촬영을 시작하고 공통 시작 표식을 남긴다.
2. 작업자가 위 안내를 듣기 시작한 시각을 전체 시간의 시작으로 쓴다.
   준비 시간, API·측정 대기, 작업 시간, 중단 시간을 따로 적는다.
3. [D01 안내서](d01-repair-operator.md)를 따른다. 작업자 확인은 실제 요청이
   나온 뒤 실제 완료 보고를 받아 저장한다. 빈 양식을 완료 보고로 대신 쓰지 않는다.
4. 요청마다 요청 ID·표시 문구·보고 시각·배선 변경 횟수·질문을 남긴다.
   안내자가 말을 보충하거나 직접 배선을 만지면 내용과 이유를 적는다.
5. 모델 또는 가드가 보류하면 그 실행은 보류다. 별도 확인 없는 RESET, 자동 재시도,
   실패를 지우고 새 성공만 남기기는 하지 않는다. 도움을 준 뒤 계속했다면 지원받은 실행이다.
6. 마지막 판정 화면에서 타이머를 끝낸다. 2시간에 도달하거나 작업자가 중단을 원하면
   중단 결과를 남긴다. API·계측 문제로 멈춘 시간도 전체 시간에서 몰래 빼지 않는다.

계측 실패와 사용자 혼동을 구분할 자료는 남기되, 로그만으로 원인을 단정하지 않는다.
실행기의 가드·부팅·배선 확인 기록과 관찰 메모를 함께 검토한다.

## 결과 한 줄을 쓰는 규칙

- 완료: “작업자 P01이 [사전 경험] 상태에서, [사전 설명]을 받은 뒤 D01 수리 절차를
  [전체 시간]에 완료했다. 질문 [횟수], 추가 설명 [횟수], 직접 배선 개입 [횟수].”
- 중단: “P01 세션은 [단계]에서 [관찰된 이유]로 중단됐다. [시간/도움/계측 로그]를 보존했다.”
- “혼자”, “도움 없이”는 추가 설명·직접 개입이 실제로 0인 경우에만 쓴다.
- “비전문가”는 사전 경험 기록이 뒷받침할 때만 쓴다. 한 명의 사례를 성공률로 바꾸지 않는다.
- 실물 수리의 성공 판정은 관찰자의 인상이 아니라 고정 프로토콜의 두 검증 결과를 따른다.

기록 시작점: [빈 관찰 기록](../examples/participant-session/blank.json).
지금 파일은 `template_only: true`이며, 실제 수행·동의·배선 확인을 뜻하지 않는다.
