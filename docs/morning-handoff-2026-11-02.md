## 하드웨어 현재 상태와 아침 순서

밤 동안 USB, RESET, DAC, ADC에 명령을 보내지 않았음. 마지막 실제 사용자 확인은
`USB 분리 / C 2개 설치 / 네 곳 삐확인 / 나머지 유지`임. 밤 사이 연결됐다고 가정하지 않음.

1. 정상 설계가 10kΩ·1µF임을 실제로 확인하고 검토 파일을 저장한다. 예전 mock 검토 파일을 쓰지 않는다.
2. 준비한 D01 그대로 촬영을 시작한다. 프로브를 제거한 뒤 같은 USB 케이블·포트 연결을 실제 확인한다.
   다이오드는 회로 밖, 큰 OUT 부하·IN 분기·996Ω 션트는 없는 시작 상태다.
3. 기존 고정 프로토콜로 D01 실물 수리를 시작한다. 추가 멀티미터 전압 중심 맞춤은 요구하지 않는다.
4. Spark의 부하 요청 때만 USB-off 후 E30–A55 연결. 수리 예측의 원격 게시가 확인된 뒤에만
   USB-off 후 I8–I13 추가 C 제거. 실제 완료 보고를 실행 담당자가 기록한다.
5. 두 수리 후 검사까지 끝나면 결과와 실제 마지막 부팅 ID를 보존한다.
6. 그 뒤 원래 C와 OUT 부하를 USB-off 상태에서 제거해 B5 저항 대조 시작 상태로 전환한다.
   B5 프로토콜의 소스 목록과 직전 부팅은 이 시점의 실제 상태로 갱신·푸시해야 한다.
   D01 이후 부팅 ID를 미리 만들어 넣지 않았다.

상세 배선은 [D01 안내서](d01-repair-operator.md), [B5 안내서](b5-operator.md).
수리 실물 → B5 실물 → 다른 사람의 완수 순서 유지. 영상 원본은 `video/raw/`에 두고 공개 커밋에서 제외한다.

## 해석과 편집 결정

- 순위를 숨긴 Spark가 엔진보다 낫다는 문구는 쓰지 않는다. 선형 과제에서는 엔진 순위를 유지한다.
- B5 반복은 개발 점검이다. 실물·새 회로 일반화 성적과 합치지 않는다.
- 명령 입력 사전 예측과 실측 IN 조건부 판정을 구분한다. 사전 예측만 빗나갔는데
  조건부 검증은 통과했다면 두 결과를 모두 보여 준다.
- 제출 테마는 사용자 목표인 Push the Frontier로 유지한다.
- 백업 영상의 새 음성과 타임라인은 생성 완료했다. 이후 실물 장면을 넣을 때는 그 실행의 실제 문구·수치로 교체한다.
- `video/out/benchmark-evaluation.png`와 모의 수리 리플레이는 미리보기이며 실물 촬영을 대신하지 않는다.

## B5 변형 선정 종료

고정한 계산 예산으로 진행한 선정 작업은 종료했다. 한도는 맞추기 사이에 검사하므로
마지막 맞추기의 종료만큼 초과할 수 있으며 실제 경과 시간은 원문에 남겼다. 등록 13개 중 5개에 선정 분류가
남았고, 나머지는 `selection_incomplete`로 보존했다. 주 평가에 선정된 변형은 **0개**다.
선정 규칙·후보·난수·실행기 코드는 도중에 바꾸지 않았고, 맞추기 실패를 대안 탈락으로
세지 않았다. 실제 Spark 최종 평가는 실행하지 않았다.
[전체 선정 결과](../examples/b5-variants/2026-11-02/SELECTION.md)와 원문을 푸시했다.

이 결과에는 정확도 X/N을 붙일 수 없다. 0%나 100%로 표시하지 않고, 이번 영상의
넓은 구조 발견 성능표는 제외한다. 실물 D01 수리와 B5 실행에 시간을 우선 쓴다.

밤 작업은 모두 종료했다. 미완료 선정 항목까지 포함해 기록을 보존했고, 추가 모델
요청이나 하드웨어 작업은 돌고 있지 않다.
