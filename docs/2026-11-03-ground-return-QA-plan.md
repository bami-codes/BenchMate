# GND 귀환선 한 곳 정비 후 자동 QA

ADC 모드 0→1→2→0 대조는 모두 기존 3 mV 기준을 넘었다. 읽기 방식만으로 고쳐지지 않았다.
원본 펌웨어를 복원하고 새 부팅·비무장 상태를 확인했다. 추가 유료 호출은 0회다.

다음은 MCU GND와 큰 보드 파란 GND 레일 사이의 기존 귀환선 한 곳만 정비하는 계획이다.
앞선 DMM의 검정 프로브는 파란 레일에 있었으므로, 그 레일과 MCU GND 사이의 이동을 직접
분리하지 못한다. 공통 귀환 경로의 전압 강하가 기여할 수 있다는 가설이며 아직 확인된 원인이 아니다.
추가 펌웨어 실험이나 손으로 하는 mV 반복 판독보다 먼저 이 경로를 한 번 확인한다.

USB를 빼고 LED가 꺼진 뒤, 현재 Arduino GND 표시 핀과 큰 보드 파란 GND 레일을 잇는 선만
회로 밖에서 통전 확인한 새 선으로 교체한다. 양끝은 기존 자리 그대로 사용한다.
5V·REF·A1–A4·DUT·1 kΩ과 새 D50–G50 점퍼를 유지하고 E30–A55 부하는 없는 상태를 유지한다.
프로브를 치운 뒤 같은 USB로 재연결한다. 완료 보고 전에는 실행하지 않는다.

원본 펌웨어에서 새 부팅과 비무장 상태를 확인한 뒤 ARM 한 번, HOLD×3,
작은 STEP(±0.2 V), 복귀 HOLD, 큰 STEP(±0.5 V), 복귀 HOLD를 최대 한 번 실행한다.
모든 기존 전기적·타이밍·3 mV 검사를 그대로 쓰고 첫 실패에서 멈춘다. 자동 취득은 통상 1분 안팎이다.
이것은 계측기 정비 QA이며 Spark의 실험 선택을 대신하는 진단이나 집계 대상이 아니다.
추가 Spark/API 호출 0회·$0, 펌웨어 업로드 0회다. 소스·계획·작업 보고·원시 응답을 보존한다.
