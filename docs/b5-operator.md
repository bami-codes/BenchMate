# B5 무부하 실물 실행 안내 — ADC v2

이 문서는 **앞으로 실행할 절차**다. 모의 실행 통과는 실물 B5 통과가 아니다.
10월 31일 14시 이후 실물 작업을 목표로 준비한다. 기존 4.7kΩ/9.99kΩ
부하 교체 검증은 별도 미완료 항목으로 남긴다. 이 실행에서는 멀티미터
**전압 측정을 요청하지 않는다.** 통전 확인은 USB를 뽑고 LED가 꺼진 상태에서만 한다.

## 시작 상태와 저항 대조

마지막 보고 이후 USB 분리 여부는 확인되지 않았다. 실행 담당자는 먼저
현재 상태와 **USB 분리 → 아래 배선 확인 → 재연결**의 실제 완료 보고를 받는다.
옛 연결 완료 메시지나 모의 실행의 확인을 재사용하지 않는다.

1. USB를 뽑고 LED가 꺼질 때까지 기다린다.
2. 미니보드 B3–B8의 10kΩ 저항을 유지한다. 원래 C(D8–D13)와 추가
   C(I8–I13)는 둘 다 없어야 한다. 다이오드는 아직 회로 밖에 둔다.
3. 미니보드 IN A3, OUT A8, REF A13 연결선과 E8–F8/E13–F13 점퍼를 유지한다.
4. 큰 보드 11번 B28–B35 우회 점퍼와 14번 B50–B23을 유지한다.
   996Ω 션트, A55–C35 IN 분기, E30–A55 OUT 부하 점퍼는 없어야 한다.
   D55–D60의 9.99kΩ 저항과 C23–A60 REF선은 유지하며 D55 쪽은 떠 있다.
5. 무전원 통전으로 **미니 D8↔큰 E30 OUT**, **미니 D13↔큰 D50 REF**가
   각각 삐인지 확인한다. 다이오드나 10kΩ 저항 자체의 양 끝을 삐로 판정하지 않는다.
6. 프로브를 제거하고 같은 케이블·맥 포트에 USB를 연결한다.
   `USB 분리 후 저항 대조 배선 확인 / OUT 삐·REF 삐 / USB 재연결`로 보고한다.

새 부팅 확인 뒤 한 번 ARM한다. ±0.2V 1Hz 사인 → ±0.5V 스텝 → ±0.8V
1Hz 사인 순서로 입력·출력 ADC 경로를 비교한다. 각 파형 전후 HOLD를 포함한다.
전체와 각 구간 RMS가 모두 9mV 이하여야 다음 단계로 간다. 이 검사는
절대 전압 교정이 아니며, 실패하면 진폭을 올리거나 다이오드를 설치하지 않는다.

## 요청이 왔을 때만 다이오드 설치

모델에는 무기명 시편 준비 도구만 보인다. 아래 부품명·구멍·방향은
로컬 작업자 안내이며 모델에 시편 정답으로 전달하지 않는다.

1. 프로그램의 작업자 요청이 나오면 USB를 뽑고 LED가 꺼질 때까지 기다린다.
2. 이미 확인한 **1N4148** 한 개를 설치한다.
   - **띠 없는 쪽(애노드) → 미니보드 D8, OUT**
   - **띠 있는 쪽(캐소드) → 미니보드 D13, REF**
3. 앞 단계의 저항·연결선·11/14번 점퍼를 모두 유지한다. 두 C와 두 부하/분기
   점퍼는 계속 없어야 한다. 새 부하나 션트는 설치하지 않는다.
4. 무전원에서 다이오드 금속 다리 D8↔큰 E30, D13↔큰 D50이 각각 삐인지
   확인한다. 방향은 **띠의 위치를 눈으로 확인**한다. 다이오드 양 끝의
   통전 여부를 단락 판정에 사용하지 않는다.
5. 프로브를 제거하고 같은 USB에 연결한다.
   `USB 분리 / 1N4148 띠 없는 D8·띠 있는 D13 / OUT 삐·REF 삐 / 나머지 유지 / USB 재연결`
   로 보고한다. 실행 담당자가 해당 요청 ID와 실제 원문을 기록한다.

## 자동 학습·검증 동안

다이오드 설치 이후에는 **USB·배선·RESET을 건드리지 않는다.** 학습은
±0.2V 1Hz 사인, ±0.5V 스텝, ±0.8V 1Hz 사인이다. 필요하면 모델이
저진폭 반복을 한 번 고를 수 있으나 정보가 부족한 선택으로 그대로 기록한다.

최대 두 개 구조 제안을 허용한다. 학습이 통과하면 구조·매개변수·상수 REF
보정·채널 차이 보정과 **명령 입력 기준 사전 예측**을 저장·커밋·푸시한다.
원격 커밋 확인 후에만 ±0.35V 스텝과 ±0.65V 5Hz 사인을 측정한다.
그때 얻은 IN을 반영한 조건부 예측은 별도로 기록한다. 예약 OUT으로
모델이나 보정을 다시 맞추지 않는다. 사전 예측과 조건부 예측의 점수도 각각 남긴다.

각 부팅의 첫 HOLD A1 평균 하나를 모든 채널의 공통 좌표 원점으로 고정한다.
A4 절대값은 REF 교정값으로 쓰지 않는다. A4 블록 평균 범위와 정지 구간
각 경로 평균 범위는 같은 부팅 내 3mV 이하여야 한다. 레일·파형 코드·타이밍
검사도 유지한다. ADC 경로의 전압 환산은 기존 잠정값이며 공급 전압을 새로
측정했다고 기록하지 않는다.

## 멈추는 조건

통신 무응답, 예상하지 않은 부팅 변경, 가드 실패, 대조 실패, 게시 실패,
시뮬레이터 한도, 예약 검증 실패는 해당 기록에 남긴다. 자동 RESET·재ARM·
재측정·다른 값으로 재맞춤은 없다. 오류의 원인을 확인하기 전 반복 실행하지 않는다.
예약 비교가 실패하면 검증 결론을 보류한다. 프로그램은 종료 시 출력 상태를
확인할 수 없는 경우도 명시한다. 작업이 끝나거나 중단되면 USB를 분리한다.

## 실행 담당자용

`scripts/b5_unloaded.py`의 mock과 physical은 같은 `B5Session` 도구와 모델/
검증 절차를 사용한다. 실물은 별도 `PhysicalB5Bench`에서 기존 바이트 프로토콜,
단일 ARM, 부팅 연속성, 원시 프레임 보존을 사용한다.

실물 시작 전 현재 소스 전체 SHA-256과 `b5_protocol`, 기존 ADC 변환값,
전원 설정, 직전 부팅 ID를 프로토콜 JSON으로 고정하고 푸시한다. 초기 실제
작업자 보고를 별도 JSON으로 넣는다. 스크립트는 프로토콜 소스 불일치와
초기 확인 누락을 API 호출 전에 거부한다.

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python scripts/b5_unloaded.py \
  --bench physical --provider meta --publish-freeze \
  --protocol PATH_TO_FROZEN_PROTOCOL --initial-report PATH_TO_ACTUAL_REPORT
```

API는 Spark max, 최대 8회, 자동 재시도 없음. 전송은 도구 명세·설정·학습
파형당 25개 요약 지점·오차·생성 구조·검증 요약이다. 전체 ADC, 조립 안내,
이전 시편 결과, 키, 로컬 파일 내용은 입력에 넣지 않는다. 예약 출력은
수집 전에는 없으며, 수집 후에는 검증 요약으로만 전달한다.

이 결과로 주장할 수 있는 것은 **선형 후보 밖 구조의 무부하 예측 성능**이다.
유일한 회로 정답, R/Is 개별 식별, 절대 REF 정확도, 부하 외삽 통과를 주장하지 않는다.
