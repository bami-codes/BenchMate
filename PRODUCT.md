# BenchMate

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The current surface serves international hackathon judges watching a demonstration and the solo developer reviewing experiment evidence. The user explicitly chose demonstration and result review as the first-screen priority, with the same screen later receiving live board data.

## Product Purpose

Choose circuit measurements, propose an explanation, commit a prediction before the next observation, and test that prediction. The product must make the difference between model judgment, numerical analysis and human mounting visible.

## Operating Context

English presentation at the Meta Global AI Developer Hackathon. Offline, self-contained HTML records are already supported. A shared renderer will also receive append-only live run events. Physical board integration follows D2 calibration; a live software log must never imply calibrated hardware.

## Capabilities and Constraints

- The first viewport must show observed and precommitted predicted traces, the three-field report, an action timeline with actor badges, illustrated mounting instructions, and independent data-origin and viewing-mode labels.
- Existing event records and their source hashes are immutable evidence. No fabricated model quotes, success claims, precision, latency, confidence or physical operations.
- Current diagnosis and repair examples are synthetic. Real Muse Spark API calls are distinguishable from engine-only runs. Library mismatch tests are development evidence, not physical diode characterization.
- English is the interface and new model-report language. Historical original reports remain original data and may be inspected as such.
- Retain keyboard operation, responsive layout, reduced-motion behavior and export. No external runtime dependencies are needed to open a report.

## Brand Commitments

BenchMate is the name. The user delegated visual direction and skill selection, asking for a designer-level result suitable for a first-place attempt. No winning guarantee is a product claim.

## Evidence on Hand

Hash-verified JSONL in examples/, generated and fitted circuit elements, committed waveforms, observations, fit checks, explicit source and provider configuration. Hardware calibration, final holdout performance, baseline superiority and reliability are not established.

## Product Principles

- The waveform is the evidence, not decoration.
- Preserve the order: predict first, observe second.
- Make the responsible actor visible at each consequential step.
- Expose uncertainty beside the conclusion.
- Separate live/replay transport from synthetic/physical origin.
